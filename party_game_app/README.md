# 聚会桌游吧 (PartyGame Club) 跨平台独立客户端

本工程是专为聚会娱乐场景打造的独立跨平台客户端，支持一次编写，多端同构编译部署至 **Android、iOS、鸿蒙 (HarmonyOS Next / OpenHarmony)、Web** 等多平台。

---

## 🎮 包含的聚会游戏矩阵

1. **大话骰 (吹牛 Liar's Dice)**：
   - 3D 拟真摇蛊骰盅、物理碰撞摇骰微触感震动反馈；
   - 叫点、劈骰、报斋、反斋、叫点合法性智能裁决；
   - 经典多难度性格陪玩 AI（激进狂徒、保守老狗、顺风神算、平衡博弈）；
   - 本地同屏轮流玩 (Pass & Play) 盲盒遮挡隐私模式，一部手机即可畅玩聚会。

2. **谁是牛头王 (Take 6 / 6 Nimmt!)**：
   - 1-104 张带牛头数值卡牌，经典 4 排放置规则与第 6 张牛头爆排吃牌惩罚；
   - 智能比牌放置动画、多轮计分板；
   - 6 位数字房间码快速对决与多席位 AI 填补。

3. **聚会大冒险转盘 (Party Wheel)**：
   - 拟真减速阻尼旋转物理指针；
   - 真心话 / 大冒险随机抽题库与趣味喝酒惩罚词条；
   - 支持自定义转盘惩罚规则与概率权重。

4. **谁是卧底 (Undercover)**：
   - 自动生成平民词与卧底词对库（如 "西瓜" vs "哈密瓜"）；
   - 玩家暗查底牌、轮流发言记录、多轮无记名投票放逐裁决；
   - 卧底反杀获胜与平民检举获胜结算。

## 💬 社交、交流与趣味互动体系

- **用户全场景认证**：
  - 手机验证码快捷登录；
  - 账号与密码登录 / 新玩家注册；
  - 密码找回重置机制；
  - **游客免密一键体验模式 (Guest Mode)**：无需注册秒进游戏，支持后续一键绑定手机转正，永久保留金币与战绩。
- **即时交流广场**：
  - 🌐 **世界公频**：全网玩家大厅畅聊、喊人组队、战绩高光；
  - 📍 **同城酒馆**：同城附近桌游玩家交友切磋；
  - 💬 **快捷常用短语与表情**：一键预设喊话，免除繁琐打字；
  - 👥 **好友系统与 1 对 1 私信**：在线状态实时感知、私信直接发送"游戏房间对决卡片"，好友点击一键赴约。
- **全屏物理抛物线趣味投掷互动**：
  - 对局中或广场交流中，可向任一玩家投掷：**臭鸡蛋 🥚、碰啤酒 🍻、送鲜花 🌸、拍拖鞋 🥿、大炸弹 💣**；
  - 带有高帧率物理贝塞尔曲线飞掷、旋转缩放与爆裂粒子震颤特效。
- **潮友圈 (动态广场)**：
  - 分享游戏高光瞬间（如大话骰逆天翻盘、牛头王 0 吃牌完胜）；
  - 点赞与评论互动交流。
- **个性装扮商城与个人中心**：
  - 经典黑金、赛博霓虹、紫晶星系、烈焰赤龙、璀璨钻石等多种骰蛊皮肤佩戴；
  - 游戏原生触感微震动与系统音效独立开关控制。

## 🚀 跨平台编译与构建指南

### 1. 环境准备
- Flutter SDK: `>=3.27.0`
- Dart SDK: `>=3.6.0`

执行依赖拉取：
```bash
flutter pub get
```

### 2. 编译 Android 应用 (.apk / .aab)
```bash
# 生成 release apk
flutter build apk --release

# 生成 Google Play aab 包
flutter build appbundle --release
```

### 3. 编译 iOS 应用 (.ipa)
在 macOS 环境下执行：
```bash
cd ios
pod install
cd ..
flutter build ipa --release
```

### 4. 编译 鸿蒙应用 (HarmonyOS Next / OpenHarmony .hap)
本项目在 `ohos/` 目录下已预置针对 OpenHarmony 4.x / 5.0+ (API 11/12) 的完整 ArkTS 模块与声明式 UI 挂载配置：
1. 使用 **DevEco Studio** 打开项目；
2. 配置 OpenHarmony SDK 与签名证书证书；
3. 执行构建输出：
```bash
hvigorw assembleHap --mode module -p module=entry@default -p product=default --no-daemon
```

### 5. 编译 Web / 移动端 H5
```bash
flutter build web --release
```

## 📂 工程分层结构

```
party_game_app/
├── lib/
│   ├── core/                  # 核心基础（主题配色、本地持久化、音效触感引擎）
│   ├── games/                 # 游戏矩阵（大话骰、谁是牛头王、聚会转盘、谁是卧底）
│   ├── models/                # 领域模型（用户、消息、好友、战绩动态、房间席位）
│   ├── providers/             # 响应式状态管理（Auth, Chat, Friend, Room, Moment）
│   ├── services/              # 核心业务服务与本地数据仓储
│   ├── views/                 # 页面视图
│   │   ├── auth/              # 登录、注册、找回密码、游客入口
│   │   ├── hall/              # 派对大厅、游戏选择、创建/加入房间
│   │   ├── room/              # 房间席位大厅、准备/投掷互动/启动对决
│   │   ├── chat/              # 交流广场与投掷粒子覆盖层
│   │   ├── friends/           # 好友列表与一对一私信约战
│   │   ├── community/         # 潮友圈高光动态与点赞评论
│   │   └── profile/           # 个人主页、段位胜率、装扮商城、音效设置
│   └── main.dart              # 全局入口与 Provider 路由装配
├── android/                   # Android 原生宿主
├── ios/                       # iOS 原生宿主
└── ohos/                      # 鸿蒙 Next (OpenHarmony) 原生 ArkTS 宿主
```
